Make a 3D ghar from your own naksha

This is how the reel was made, step by step. It took one evening on a laptop.

What you need

  1. Claude Code, the app where Claude writes and runs the code for you. Needs a paid Claude plan. The reel used the Claude Fable 5.2 model. Opus works too.
    npm install -g @anthropic-ai/claude-code
    Then open an empty folder in a terminal and type claude.
  2. Node.js 20 or newer, from nodejs.org.
  3. three.js, for the 3D house. Claude installs it itself.
    npm install three
  4. Nano Banana Pro, Google's Gemini image model, for the real-looking photos. Get an API key at aistudio.google.com. It is paid, roughly ₹12 to ₹20 an image. The reel used 28 images.
  5. HyperFrames, to turn the page into a video.
    npx hyperframes init naksha
    Its Claude skill: npx hyperframes skills update hyperframes

The steps

1. Photograph your naksha. Flat, sharp, with every room size readable.
2. Ask Claude to build it in 3D.
Read this floor plan. Write every room and wall as data in metres, with the door and window openings. Build the house in three.js from that data: walls 2.9 m high, floors, and simple block furniture in sensible colours in each room. Show me a top-down view next to my plan so I can check the layout.
Check the sizes and tell it what is wrong. Do not move on until the walls match your plan.
3. Ask for camera spots.
Give me one camera spot at eye height in every room, and one cutaway view of the whole house from above. Save a clean 9:16 screenshot from each.
4. Turn each screenshot into a photo. Send the screenshot to Nano Banana Pro as the reference image, with this:
Turn this simple 3D render into a real photograph of the same room in a modern middle-class Indian flat. Keep the camera position, lens, perspective, walls, doors, windows, ceiling and every piece of furniture exactly where they are, with the same colours. Replace the flat blocks with real materials and real objects. Soft warm afternoon sunlight, natural shadows and bounce light. Photoreal interior photography, 24mm lens, natural colour, high detail. No people, no text, no watermark.
For night, send the new photo back with this:
Edit this photograph into the same scene at night. Keep the camera, framing, walls, furniture and every object in exactly the same position and size. Change only the light: it is night outside, and the room is lit by warm lamps with a cosy golden glow. Photoreal. No people, no text.
5. Make the camera move.
Project each photo back onto the 3D scene from the same camera that made its screenshot, so I can move the camera a little inside each room. Put a flat disc where each ceiling fan is, so the fan is not painted twice.
6. Make the video.
Make a 9:16 HyperFrames video: the plan lies on a desk, the walls rise out of it, then the camera walks through every room. Each room wipes from the 3D model to its photo, then to night.

Three rules that matter

  • Never let the image model invent the layout. Always give it the 3D screenshot.
  • The 3D screenshot and the photo must come from the same camera. That is why the walls stay in place.
  • This is a picture of a home, not a construction drawing. An architect or engineer must design the real house.

In the reel: the 3D house, the edit and this page were made by Claude Fable 5.2 in Claude Code. The real-looking rooms and the views from space are AI images made with Nano Banana Pro on top of that 3D house. The music is AI-made. The plan is a sample 30×40 2BHK drawn for the reel. Prices are rough and change.
